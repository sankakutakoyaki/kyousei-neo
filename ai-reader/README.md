# 文書AI読取サービス

受注FAX、将来のレシート写真などを、ローカルAIへ渡す小さなサービスです。Spring Bootとは別プロセスで動かします。

## GPU導入前に完了していること

- Spring BootからPDFを送る接続仕様
- PDFの1ページ目を画像化する処理
- AIへの画像・指示文送信処理
- 受注FAXとレシートの読取形式
- 受注候補画面へ返すJSON形式

## GPU導入後の導入順

1. NVIDIAドライバを導入し、GPU認識を確認する。
2. Ollamaと画像対応モデルを導入する。
3. Pythonの仮想環境を作り、`requirements.txt` を導入する。
4. `uvicorn app.main:app --host 127.0.0.1 --port 18080` で試験起動する。
5. `GET /health` が応答することを確認する。
6. 平和堂の取込PDFで単体読取を比較する。
7. Spring Bootの `order.ai.enabled=true` を設定する。
8. systemdサービスとして常駐起動を設定する。

## 安全な運用

- APIは`127.0.0.1`でのみ待ち受け、外部公開しない。
- AI結果は候補として返し、人が確認・修正してから確定する。
- ファイルは読取処理中だけ一時領域に置き、終了時に削除する。
