# 受注一覧の配送・工事担当者

- 受注一覧に「配送・工事担当者」を追加し、既存の配車・当日班・乗務員・従業員情報から取得する。
- 通常は受注の訪問日の有効な配車だけを対象にする。再訪問予定日が決まっていれば、その日の配車を表示し、前回の担当者を混ぜない。
- 日延などで訪問日が未定の場合は、最終報告日の担当を「前回（日付）」と明記する。参照日を推測しない。
- 複数班でも同じ従業員IDは一度だけ表示。解除済みの配車・班・乗務員、削除済み従業員は除外する。
- 未配車と、配車はあるが有効な担当者がいない「担当者未設定」を区別する。
- 一覧で省略されてもマウスを合わせれば全員確認でき、受注詳細の基本タブにも全員を表示する。表示欄は入力・保存の対象に含めない。
- 既存の受注一覧・詳細取得API、データ範囲と権限、共通テーブル描画を再利用。新しい画面やDB列は追加しない。

検証：関連Javaテスト19件、JavaScript全体134件成功。開発DBで一覧・詳細のSQL、受注の重複なし、複数班の担当者重複除去、日付・解除／削除状態の除外、訪問日未定時の前回担当参照を読み取り専用で確認した。
